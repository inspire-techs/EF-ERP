# EF-ERP

The Engineers Forum Qatar digital platform.

EF Qatar is the apex body of engineers of Kerala origin working in Qatar —
around 800 members, administered by an elected committee of volunteers.
This repository carries the platform that replaces the spreadsheets,
messaging groups and cash it runs on today.

## What is here now

Design only. No application code yet.

    design/
      brand/      the EF mark, and the tokens every screen is built from
      console/    the committee-side application — 4 screens
      site/       the public home page — desktop and mobile
      archive/    superseded drafts, kept for reference

Start at [`design/README.md`](design/README.md).
