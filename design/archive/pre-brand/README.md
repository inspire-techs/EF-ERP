# Superseded — pre-brand drafts

These are the first drafts, made before EF supplied the brand guideline.
They use a maroon-only palette sampled from a low-resolution logo, with no
green, and a Source Serif / IBM Plex type pairing.

Kept for reference only. Do not build from them.

| File | Screen |
| --- | --- |
| `Main.dc.html` | Home page |
| `MyEF.dc.html` | My EF member page, desktop |
| `MyEFMobile.dc.html` | My EF member page, mobile |
| `standalone/` | The same three as plain, self-contained HTML pages |

**The My EF member page has not yet been redrawn in the real brand.** It
is the one member-facing screen still outstanding, and `MyEF.dc.html`
here is the structure to work from — zones, the five membership states and
the per-section visibility controls are all correct, only the brand is
wrong.
